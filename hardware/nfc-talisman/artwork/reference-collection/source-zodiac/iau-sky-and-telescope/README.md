The IAU formally defines constellation regions/boundaries, not one official star-connection pattern. These charts are an attributed IAU/Sky & Telescope chart convention and reference, not a uniquely official or universal line standard. The 12 common zodiacal constellations in this collection are Aries (Ari), Taurus (Tau), Gemini (Gem), Cancer (Cnc), Leo (Leo), Virgo (Vir), Libra (Lib), Scorpius (Sco), Sagittarius (Sgr), Capricornus (Cap), Aquarius (Aqr), Pisces (Psc). Ophiuchus is also intersected by the ecliptic but is not one of the conventional twelve zodiac constellations/signs.

Files use standard IAU abbreviations as basenames, with both the screen GIF and A4 PDF chart for each: Ari, Tau, Gem, Cnc, Leo, Vir, Lib, Sco, Sgr, Cap, Aqr, Psc.
