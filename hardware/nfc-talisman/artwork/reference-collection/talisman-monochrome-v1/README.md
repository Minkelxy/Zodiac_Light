## 单色与阴影的处理

每张图只使用一种实色墨：填色、描线与排线使用同一颜色。用实色区域的面积和透明开口表现明暗：原有暗部用实色，转折/亮面用透明细缝，必要时在原有较宽色块内使用少量疏密排线。边缘可抗锯齿；图案内部不使用渐变、第二种灰色或不同透明度来模拟阴影。

已有分段和未着色石面继续透明。羊、狗等原本依靠开放线条表现形体的图案，优先保持简洁；不要给所有动物补毛纹、鳞片或器官。排线不跨越分段空隙，不把独立墨岛连为完整剪影。先按小尺寸检查辨识度，再考虑是否需要更细的阴影线。
