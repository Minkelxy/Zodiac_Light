# 猴、鸡、狗、猪单色复核

本记录对照 `source-talisman`、`talisman-patterns` 与 `talisman-restored-v1` 的四张图。目标是忠于源图结构的严格单墨色绘制。每张仅用一种不透明墨色和透明负空间；透明度只用于边缘抗锯齿。不得用半透明墨、灰阶或渐变模拟阴影。源图中的空隙、未着色石面及构件间隔必须保持透明，不得补画毛纹、器官或装饰。

## 猴

- **主体与方向：**一只侧身猴，头脸位于右上并朝右；左侧是大幅回卷的尾，身体与肢体以细长弧带构成。
- **对照：**修复图保留了主要轮廓关系，但尾、身体和肢体的带宽明显扩大，局部的细线形结构变成较厚的实体带，并出现渐变明暗。
- **单色建议：**沿用源图的细长轮廓和尖端，以不透明墨色表现原有着色部分；用透明缝隙保留卷尾内圈、各肢体之间及身体周围的原始间隔。源图没有的阴影形状不要补入。

## 鸡

- **主体与方向：**一只公鸡，头冠和喙在右上、朝右；尾羽向左上展开，躯干在中右部，脚爪向下。
- **对照：**源图的红色主片本来就是分段结构；修复图仍保留这些主要分段。变化集中在色块面积扩大、线宽变粗及局部渐变，不能描述成主片被完全合并。
- **单色建议：**以单一实墨保留尾羽、躯干、头部与脚爪各自的源有形色块和边界；保留源图片段之间的透明缝隙及内部灰石留白。只用原有轮廓和结构线表达形状，不新增羽纹或细节。

## 狗

- **主体与方向：**一只站立侧身犬，头和口鼻朝右，卷尾在左，四肢向下。
- **对照：**当前修复图中央躯干仍保留大块透明留白；不应写成躯干已整体涂黄。源图本身也以灰石面作为身体中央的未着色区域，外围只有局部黄色线形和色块。
- **单色建议：**保持胸腹和背腹中央的大块透明区，只以不透明墨色描绘源图中有色的细弧、腿爪、头部局部及轮廓；卷尾内圈与肢体间隙也保持透明。不要用实心剪影填满躯干。

## 猪

- **主体与方向：**一只侧脸猪。源图中鼻吻相对眼和脸部主体向左突出，因此朝左；脸右侧另有独立弯月状块，脸下方还有弧形构件。
- **对照：**修复图保留了上方长弧、脸部及右侧弯月等主要分区，但源图最下方偏左的大长弧在修复图中只剩中部短弯，属于明确缺失，**优先补回该长弧及其源有位置关系**。修复图的粉色分层和渐变不属于严格单墨效果。
- **单色建议：**用同一不透明墨色保留上方长弧、脸、右侧弯月、下方大长弧及中部短弯的原有分离关系和端点；构件之间留透明，不以相连色块替代。仅保留源图已有的线条与负形，不增加耳内线、皱纹或装饰。

## 输出约束

严格使用一种不透明墨色；所有阴影和结构通过源图已有的墨色线条、实体片段与透明负空间表达，不使用透明度层次、第二墨色或渐变。当前记录是复核与绘制约束；本轮没有生成单色成品，也没有改变现有修复 PNG 的内容。参考指南 PNG 仅排版放大，等待原生 ImageGen 恢复后继续重绘。
