# 射手座星图与 LED 布局复核

日期：2026-10-11。依据当前制造快照、星孔/槽几何、单色马图与原厂 LED 资料。未修改原生 PCB、孔槽、天线或 Gerber；无实物光效结果。

**结论：八星茶壶图适合作为首版图案，视觉上最值得改进的是文字风格和星点/长槽的主次。LED 电路分支正确、元件位于 AF30 腔体投影内，光学耦合和八星均匀出光仍待样片验证。优先验证导光/扩散结构，暂不为对称而移动 LED。**

## 星图与美观

星心横跨 27.5 mm、高约 17.59 mm，放入 37 mm 八边形后留白充分。八颗主要星与十一条连接保留了茶壶的辨识结构，无需增加完整星座的其余星点。现有孔槽均在 30 mm 内窗投影内；文件审计记录离内窗边界最小约 0.85 mm，材料桥约 1.03 mm。它们是名义几何值，尚未经过实际刀补和加工确认。

主观审美上，深底浅线适合这枚硬币；现有字高约 1.2 mm、笔画 0.18 mm 的折线字较生硬，底部 `FORTIS ET LIBER` 又长于上部 `AD ASTRA`。另做常规字体和较短文字的独立候选，保留原星位、孔径、槽宽及深底浅线。实际查看本轮 PNG 后，更倾向 B 的 `SAGITTARIUS / AD ASTRA`：上下字长更平衡，衬线字与边框更柔和；但文字较细，仍须在 1:1 打印和印刷预览上确认，转为轮廓后复查笔画。候选未导入 EDA。

八孔总面积约 **4.02 mm²**，十一槽总面积约 **66.36 mm²**，约为星孔总面积的 **16.5 倍**。宽 1 mm 的长槽容易成为视觉主角，尤其底部最长槽，八星点会显得较小。这个面积比例不是亮度比，也不能说明槽“消耗了”多少光。暂保留已检查过的机械孔槽，先通过字形、留白、印刷层和扩散样件确认视觉主次；如需改孔径或槽宽，作为下一版机械变更重新审查桥宽及 CAM。

现有彩印 PNG 在孔槽周边保留 0.20 mm 透明缓冲。按当前白色阻焊＋彩印候选路线，该缓冲会露出白色阻焊底；校样只模拟这一露底效果，不代表实际油墨与基材颜色。日间槽周边浅色带的名义外宽约 1.4 mm（孔周边为约 1.2 mm），其中中央孔槽仍是暗色开口，并非整条浅色带都会发光。丝印补线、星环和文字只用于关灯时的辨识；夜间开口是否亮、是否均匀由光路决定。

## LED 位置与坐标

原生 PCB 使用 Y 向上的局部坐标，星图 SVG 使用 X 向右、Y 向下。从同一基准上边绕竖轴翻看成品背面时，后盖外视坐标为 `(-x_native, -y_native)`；正面外视为 `(x_native, -y_native)`。规则八边形仍需按装配说明标记基准边，不能随意再转 45°。

| 灯 | 核心板原生局部中心（mm，四舍五入） | 对应外侧图案坐标（mm，X右Y下） |
|---|---|---|
| D1 / Top | (-5.994, 0) | 马面 (-5.994, 0) |
| D2 / Top | (+6, +4) | 马面 (+6, -4) |
| D3 / Bottom | (-6, 0) | 射手座 (+6, 0) |
| D4 / Bottom | (+6, -4) | 射手座 (-6, +4) |

八颗星到最近后面 LED 中心的平面距离为 **1.58–10.01 mm**；最近为 δ，最远为 λ。D4 自身离最近 ζ 星孔约 5.41 mm。逐孔距离见图与 JSON；这些是封装中心的定位距离，不是已知发光芯片中心或光强。旧 v3 光学距离段混用 Y 方向，本轮统一坐标后的数据取代该段。

只针对八个星心、完全忽略焊盘/电阻/走线/槽/材料的双圆覆盖下限为约 9.56 mm，较当前最远近源距只改善约 4.55%。这不是可落板优化。简单把两灯移到外视 `(±7,0)`，最远近源距反而约 10.53 mm；分区调整也会改变近槽热点和走线。现阶段没有充分依据为几何对称重排灯、电阻或射频区域。

## 浅腔和星孔隧道

APG1608SYKC/T 为顶发光，平面旋转不会改变光轴朝向。原厂 V15B 资料给出 **120°全半强度视角**，即 ±60°处光强约降至轴向峰值的一半；它不是光束截止角或均匀光斑。在假设 LED 发光面距盖板内侧 `h=1 mm` 时，该角的平面投影半径为约 1.73 mm。真实 h 受器件发光面、焊锡、胶层及板厚影响，尚未测量。[Kingbright 原厂规格](https://www.kingbrightusa.com/images/catalog/SPEC/APG1608SYKC-T.pdf)

还必须考虑孔壁。对点源、直圆孔半径 R、盖板厚 t、点源到内孔面的间隔 h，存在穿过孔内外两个面的直线通路要求：

`d ≤ R × (1 + 2h/t)`。

取名义 `R=0.4 mm、t=1 mm`，在 `h=1 mm` 示例中最大偏心仅 1.2 mm；在 `h=0.75 mm` 示例中为 1.0 mm。当前最近星孔的灯封装中心偏心约 1.58 mm，已超过这个理想点源边界。把盖板厚度加到总轴向距离后只检查 LED 视角，会忽略孔壁遮挡。

这个推导不能判定实物一定不亮：有限发光区、封装折射、孔壁/FR-4 散射、倒角、公差、实际胶层、扩散片与导光结构都未建模。原厂没有给出这里所需的有效发光区尺寸。可以确定的是，现有坐标和 LED 视角不足以保证八星直达出光，样件需把每颗星及每条槽分别记录。

## 电气和下一步

四路电气连接仍为 `VOUT → 独立2.2 kΩ → LED阳极 → 阴极GND`，前后各两颗，器件处于 AF30 腔体投影内。现有保存重开的 DRC 记录为 0，本轮没有改铜、移动器件或重复执行 DRC。两灯减载版只剩 D1 / D3，背面覆盖更有限，须独立完成其光效验收。

建议先按既有电路干装，比较无扩散、薄非金属扩散片、适合该薄腔的非金属导光候选。扩散片放在盖板内侧覆盖孔槽时需避让元件、胶区并实测净高；薄扩散片能否充分混光仍未知。分别拍日间无光、暗场通电，并对八孔/十一槽记录亮点、热点和遮挡。不得靠增加灯数或降低电阻值来跳过 VOUT、RF 和读写测试。

马面尚未落实透光分区，连续 1 mm FR-4、彩墨和去铜/去阻焊的组合还需样片；前面的 D1/D2 分别位于马头和鬃毛投影附近，但不能据此证明马形整体柔光。先确定要发光的印刷/留白分区，再决定前面灯的位置。保留用户手动导入马图的方式。

本轮不改变马图、制造快照或加工参数。星图候选、LED 图和简化模型都是评审资料；光学样件、手机读写及最终 CAM 仍待实测/确认。
