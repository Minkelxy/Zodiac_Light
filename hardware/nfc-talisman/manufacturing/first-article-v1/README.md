# First article pack v1（离线审阅包）

**未制造、未实物试装、未供应商 CAM 审查；未放行。** 所有 CSV 均为未测试空模板，没有实测 PASS。

- `assembly-acceptance.svg`：一页装配顺序、37/30 mm 规则八边形平面、3.5 mm 胶环、TP 坐标和未验证状态；对应 PNG 为浏览器实渲染检查图。
- `configuration-measurements-template.csv`：裸板/干装/胶合 × off/2/4 LED 配置级记录。四灯为默认；off 仅诊断。
- `ndef-content-validation-template.csv`：按手机及外侧记录 URL 写入/回读、改写文本/回读。仅确认是新空白芯片时才记录初始化格式化；已有有效 NDEF 不重新初始化。
- `phone-contact-trials-template.csv`：每次独立重触碰读取一行。360 行覆盖可选矩阵，但每轮不要求全填；只记录读取，不要求每次写入或擦写。
- `cam-process-checklist.md`：文件哈希、孔槽、PTH 重复程序、工艺边、彩图和 CAM 待审项。

测试先做 B4（裸板四灯）与 S4（干装四灯）。每台手机、每面先做一次 URL 写入/回读及文本改写/回读，然后执行 10 次独立移开再触碰读取。新空白芯片仅首次按原有条件初始化；不对每次读取重复写入/擦除。若 B4 或 S4 通信不稳，再测 B2/S2（D2、D4 不装，R2/R4 保留）；仍需诊断时做全灯 DNP 无负载。只有干装验收通过后才胶合；胶合固化后复测。

暗场马形与八星需可辨认，允许扫描时闪烁。读距、VOUT 与绝对亮度不设臆造阈值，记录用户目标（若有）、测量条件与实际证据。

若最终选择两灯成品，明确记录其配置，并完成两灯配置的全部读写、光效和胶后复测；不能用诊断结果替代成品验收。全灯 DNP 只用于诊断。

规则八边形夹具不能区分八个等价旋转位置。试装时用可移除标签标基准边与层序，从两面查看马头、星图和文字方向并记录翻转方式；方向确认后才胶合，不新增成品定位孔。
