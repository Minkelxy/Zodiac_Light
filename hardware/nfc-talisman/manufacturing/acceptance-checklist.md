# 样件与制造放行验收清单

每项记录日期、样件版本、仪器/软件、结果和证据文件。未实测的项目保持“未验收”；不以离线几何检查代替实物或 CAM 验收。

截至 2026-10-10，核心板与拼板已完成布线，保存、关闭、重开后的原生 DRC 均返回空数组；天线桥接铜皮也已完成原生往返确认。`manufacturing/draft/` 已有 Gerber/钻孔 ZIP（当前文件版本和SHA-256见 `export-manifest.json`）、导出清单 `export-manifest.json`、原始 all 文件及DNP筛选后的四灯/两灯文件。ZIP CRC与只读CAM初检通过；正式刀补/工艺评审仍待完成，草案未放行。all原始15件不能直接装配；默认四灯版排除CT2为14件，两灯减载版排除CT2/D2/D4为12件，R2/R4仍Fit。默认配置仍为四灯，只有CT2固定DNP。当前Gerber使用`colorSilkscreen=false`，未包含马图或彩印。下列 RF、手机、图案、正式CAM工艺评审与最终制造放行项目仍待完成。

## 电气与装配

- [ ] 裸核心板测量 NFC 谐振/读距，记录测量方法、读距及线圈/电容配置。
- [ ] 五层叠装、未粘合时复测谐振与手机读距；确认叠装导致的变化可接受。
- [ ] 测量 VOUT，记录供电/读卡条件及稳定性。
- [ ] 检查正反两面 LED；分别验证点亮，并确认减载后仍满足亮度与 VOUT 要求。
- [ ] Android 手机正反面各完成至少 10 次读写；记录机型、系统、方向、结果和失败次数。
- [ ] iPhone 手机正反面各完成至少 10 次读写；记录机型、系统、方向、结果和失败次数。
- [ ] 干式试装五片，确认器件不顶盖、内腔和光槽无遮挡、板边/毛刺不妨碍对齐；确认后再试胶合。

## 图案与光路

- [ ] 用户在嘉立创EDA中手工导入马图：中心 `(20.5, 23.5) mm`，方向按参考、不镜像；检查尺寸、位置及彩印预览。当前 Gerber 尚未包含该图或彩印。
- [ ] 实物检查马面与射手座图案的朝向、对齐、颜色和表面效果。
- [ ] 分别检查两面 LED 经垫环、盖板、马图彩印及星孔/光槽的出光；记录遮光、漏光和均匀性。
- [ ] 若图案或板材遮光，先修订光路设计并重新试样；不可将未验证的透光效果视为通过。

## CAM、工艺与制造文件

- [x] 只读CAM初检核对22/22条GKO路径显式闭合、10个PTH/108个NPTH位置、线圈与引出铜一致性；TP1/TP2铜、阻焊开窗及无钢网开窗均通过，且不在BOM/PnP。
- [ ] 在 CAM 完成刀径补偿、槽加工、最窄实材桥及加工连续性评审；核对两个内容相同10孔位的PTH文件并确保只执行一份。
- [ ] 检查 3 mm 上下工艺边是否满足实际加工/贴装方式；确认定位、支撑与拼板方向。
- [ ] 核查邮票孔为 NPTH、孔径/间距/残边及分板耳；核查八颗星孔和板内开槽尺寸。
- [x] 核心板与拼板原生 DRC 在保存、关闭、重开后均返回空结果；当前SCH/PCB网表不一致已清除。
- [x] 天线填充桥接铜属性经原生保存重开确认：`isBridgingCopper=true`、`networkList=['ANT_LA','ANT_LB']`；10个0.30 mm钻孔/0.55 mm铜径过孔通过两板原生规则。
- [ ] 完成原理图 ERC 警告复核；检查线圈、调谐网络及跨网连接在最终 Gerber 和 CAM 中一致。
- [ ] 复核 `manufacturing/draft/` 中的 Gerber/钻孔 ZIP、`export-manifest.json` 及 BOM/PnP；选择默认四灯（14件）或减载两灯（12件）筛选版，确认DNP与坐标、单位、原点、层名、方向、孔类和版本一致。all原始15件不可直接装配。按要求重新导出包含马图/彩印的制造数据。
- [ ] 归档最终制造包及 CAM 评审记录；确认与完成实测的样件版本一致后，才签署放行。
